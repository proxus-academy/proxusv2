Tests y flashcards practican la recuperación activa, pero no plantean exactamente el mismo reto. Elegir el formato adecuado depende de lo que quieras aprender.

## Usa flashcards para respuestas concretas

Son útiles para vocabulario, fórmulas, fechas, clasificaciones y relaciones que puedas expresar con una pregunta y una respuesta breves.

## Usa tests para discriminar

Las preguntas con alternativas te obligan a distinguir entre respuestas parecidas. Resultan especialmente útiles cuando el examen real usa ese formato.

## Combina ambos formatos

Empieza con flashcards para construir una base y utiliza tests para comprobar si puedes aplicar y diferenciar los conceptos. Los errores del test pueden convertirse en nuevas tarjetas de repaso.
